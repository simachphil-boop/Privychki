# Dayflow

Привычки, задачи и цели в одном спокойном месте. Local-first PWA: работает офлайн, устанавливается на телефон, данные хранятся только на устройстве.

## Возможности

- **Сегодня** — прогресс дня, привычки и задачи с отметкой в одно нажатие, быстрый ввод задач, просроченные задачи, напоминания.
- **Привычки** — четыре типа отслеживания (да/нет, количество, время, чек-лист), пять видов расписания, серии, регулярность, история по дням, архив.
- **Цели** — этапы, привязанные привычки и задачи, срок, прогресс.
- **Календарь** — месяц и неделя, недельная матрица привычек, планирование будущих дней.
- **Статистика** — периоды 7/30/90 дней и всё время, графики и наблюдения, рассчитанные только по реальным данным.
- **Профиль** — темы (светлая, тёмная, системная), русский и английский, формат времени, начало недели, уведомления, экспорт (JSON, CSV), импорт, резервные копии, удаление данных.

## Запуск

```bash
npm install
npm run dev       # разработка
npm run build     # проверка типов + сборка в dist/
npm run preview   # просмотр сборки
npm test          # модульные тесты логики расписаний и серий
```

Сборка статическая (`base: './'`) — папку `dist/` можно разместить на любом хостинге.

## Android (APK)

Приложение обёрнуто в Android-проект с помощью Capacitor (папка `android/`).

- **Готовый APK** собирается автоматически на GitHub: вкладка *Actions* → последний запуск *Android APK* → артефакт `Dayflow-apk`.
- **Локально** (нужны JDK 21 и Android SDK): `npm run android:apk`, файл появится в `android/app/build/outputs/apk/debug/`.

В Android-версии напоминания работают как системные уведомления и приходят, даже когда приложение закрыто; экспорт открывает системное меню «Поделиться».

Сборка подписана фиксированным отладочным ключом из репозитория, чтобы обновления ставились поверх без потери данных. Для публикации в магазине нужен собственный закрытый ключ.

## Устройство проекта

```
src/
  store/      модель данных (types.ts), хранилище Zustand с сохранением в localStorage, состояние интерфейса
  lib/        чистая логика: даты, расписания и серии, статистика, наблюдения, уведомления, экспорт/импорт
  ui/         дизайн-система: кнопки, переключатели, нижние листы, диалоги, уведомления, индикаторы
  features/   экраны и формы
  styles/     токены (цвет, типографика, отступы), базовые стили, компоненты, экраны
  locales/    словари ru / en
```

## Ограничения

- В браузерной версии уведомления срабатывают, пока приложение открыто или остаётся в фоне; в Android-версии — всегда.
- Синхронизации между устройствами нет; для переноса данных используйте экспорт и импорт.
